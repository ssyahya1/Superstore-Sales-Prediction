Understand the columns
Handle missing values
Remove duplicates

Yearly sales
Top products
Top customers

Correlation heatmap

Create features like:

Profit margin

Order month
Quarter
Day of week
Weekend indicator
Average customer order value

Linear Regression
Random Forest

MAE
RMSE
R²

Select the best model.
